# Business Context

This project is a loyalty system for restaurants.

Main features:
- Users register and accumulate points
- Each user has a unique QR code
- Restaurants scan QR to assign points
- Users can redeem rewards
- Promotions can increase points

Core entities:
- Usuario (user with points and QR)
- Restaurante
- MovimientoPuntos
- Promocion
- Recompensa
